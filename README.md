# Meleu Tap

## How do I install these formulae?

`brew install meleu/tap/<formula>`

Or `brew tap meleu/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "meleu/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
